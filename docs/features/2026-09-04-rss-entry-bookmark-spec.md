# RSS 文章收藏到书签需求规格

## 1. 背景与目标

RSS 阅读区右侧工具栏已经展示“收藏当前网站到书签”按钮，但按钮尚未接入业务行为。本期将该入口连接到现有书签能力，让用户在阅读 RSS 文章时识别收藏状态，并复用现有添加、编辑书签弹窗完成收藏。

收藏结果是独立的普通书签。删除 RSS 订阅或文章不会删除已经创建的书签。

## 2. 术语与数据边界

- “当前文章”指 RSS 阅读区当前选中的 `RssEntry`。
- “文章原始 URL”指当前文章的 `link`；它可以为空。
- “已收藏”指按现有书签 URL 查询规则能够找到普通书签。
- RSS 条目与书签保持独立，不增加外键、关联表或来源字段。
- 本功能不自动设置书签星标；“收藏”在本规格中等价于创建普通书签。

## 3. 主流程

1. 用户选中 RSS 文章后，系统按文章原始 URL 查询现有书签。
2. 未找到书签时，收藏按钮保持普通状态；点击打开现有添加书签弹窗。
3. 找到书签时，收藏按钮使用与“无图模式”相同的选中样式；点击直接打开现有编辑书签弹窗。
4. 添加或编辑成功后关闭弹窗、刷新书签查询与当前文章收藏状态，用户继续停留在 RSS 页面。
5. 使用现有右下角消息样式反馈成功：
   - 新建成功：`收藏成功`；
   - 编辑成功：`书签更新成功`。
6. 取消弹窗不修改数据，也不改变当前收藏状态。

## 4. 添加弹窗预填规则

从 RSS 入口打开添加书签弹窗时预填：

| 书签字段 | 来源与处理 |
| --- | --- |
| URL | RSS 文章原始 URL |
| 标题 | RSS 文章标题 |
| 描述 | RSS 摘要转为纯文本并清理首尾空白；无摘要时留空 |
| 标签 | 留空 |

- 所有预填字段仍允许用户编辑。
- 不使用完整文章正文补齐描述。
- 不保留摘要中的 HTML 标记。
- 不自动加入订阅源名称或其他标签。

## 5. 按钮状态与文案

| 状态 | 交互 | 视觉与提示 |
| --- | --- | --- |
| 无原文链接 | 禁用 | 普通样式；`该文章没有可收藏的原文链接` |
| 查询中 | 禁用重复触发 | 普通样式；`正在查询收藏状态` |
| 未收藏 | 点击打开添加弹窗 | 普通样式；`收藏当前文章到书签` |
| 已收藏 | 点击打开编辑弹窗 | 复用无图模式选中样式；`编辑已收藏书签` |
| 查询失败 | 不得视为未收藏；点击重试 | 明确异常状态；最终失败时显示一次右下角错误消息 |

- 快速切换文章时，旧文章的异步查询结果不得覆盖新文章状态。
- 自动查询失败的错误消息不得因内部重试连续出现。
- 重新选择文章或窗口重新聚焦时，应重新确认收藏状态。

## 6. 判重与编辑规则

- 沿用现有后端规则：URL 去除首尾空白后按完整字符串匹配。
- 不规范化尾斜杠、fragment、查询参数、重定向地址或常见跟踪参数。
- 命中已有 URL 等价于编辑该书签；编辑弹窗加载书签当前的 URL、标题、标签和描述。
- 用户从 RSS 入口编辑书签并将 URL 改离文章原始 URL 后，当前文章恢复为未收藏状态。
- 不从 RSS 收藏按钮直接取消收藏或删除书签。

## 7. 并发与错误处理

### 7.1 状态查询失败

- 不得将查询失败降级为“未收藏”。
- 显示一次现有样式的右下角错误消息。
- 用户点击异常状态按钮时重新查询；查询成功后再进入添加或编辑流程。

### 7.2 提交失败

- 添加和编辑失败完全沿用现有书签弹窗行为。
- 弹窗保持打开并保留用户输入。
- 继续使用弹窗现有错误展示方式，不额外重复显示右下角错误消息。

### 7.3 并发重复

若初次查询为未收藏，但提交添加前同一 URL 已从其他入口创建：

1. 识别 URL 冲突；
2. 按 URL 重新查询现有书签；
3. 关闭添加模式并打开该书签的编辑弹窗；
4. 提示 `该文章已收藏，可编辑现有书签`；
5. 不用 RSS 预填内容自动覆盖已有书签内容。

若冲突后仍无法取得现有书签，则保持添加弹窗及用户输入，并按现有提交错误方式展示错误。

## 8. 缓存与同步

- 复用现有书签查询缓存和失效机制，不引入新的全局状态库。
- 添加、编辑或删除书签成功后，应用内相关书签查询与当前 RSS 收藏状态应更新。
- 当前 RSS 页面保持挂载时，从应用其他入口产生的书签变更也应通过共享缓存失效反映到按钮状态。
- 不新增后端实时事件协议；重新聚焦窗口和重新选择文章作为补充校验时机。

## 9. 非目标

- 不新增 RSS 条目与书签的数据库关联。
- 不修改全局 URL 规范化或判重规则。
- 不自动加星、加标签或抓取文章正文。
- 不跳转到书签页或定位具体书签。
- 不从 RSS 按钮直接取消或删除收藏。
- 不修改 RSS 已读状态逻辑。
- 不新增后端收藏接口、数据库迁移或实时事件协议。

## 10. 验收标准

1. 带链接的未收藏文章显示普通按钮，点击后打开预填正确的现有添加书签弹窗。
2. 已收藏文章显示与无图模式一致的选中视觉，点击后打开对应书签的现有编辑弹窗。
3. 无链接文章的按钮保留但禁用，并提供确定的原因提示。
4. 添加与编辑成功后弹窗关闭、收藏状态刷新、用户留在 RSS 页面，并出现对应成功消息。
5. 查询失败、提交失败和并发 URL 冲突均遵循本规格，且不会误建或覆盖书签。
6. 编辑书签 URL 离开文章原始 URL 后，当前文章恢复未收藏状态。
7. 快速切换文章不会显示旧文章的查询结果。
8. 在其他入口新增、编辑或删除书签后，RSS 状态能通过缓存失效或规定的补充校验时机更新。
9. 删除 RSS 订阅后，已经创建的普通书签仍然存在。
10. 现有书签页添加、编辑、标签刷新、随机书签缓存及 RSS 已读流程无回归。
