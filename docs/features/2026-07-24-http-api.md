# bkmrx HTTP API

HTTP 服务监听 `http://127.0.0.1:8733`，无鉴权，仅供本机桌面应用和浏览器扩展使用。

桌面应用运行时访问 [`http://127.0.0.1:8733/api/docs`](http://127.0.0.1:8733/api/docs) 可查看当前完整契约。该页面由服务端源码中的 `api_docs.html` 生成，与实际路由一同维护。

## 路由概览

| 方法 | 路径 | 成功响应 |
|---|---|---|
| GET | `/api/health` | `200` 健康状态 |
| GET | `/api/bookmarks?query=&tags=&cursor=&page_size=50` | `200` 分页书签 |
| POST | `/api/bookmarks` | `201` 完整 Bookmark |
| GET | `/api/bookmarks/by-url?url=` | `200` Bookmark，未找到时 `404` |
| GET | `/api/bookmarks/:id` | `200` Bookmark |
| PATCH | `/api/bookmarks/:id` | `200` 更新后的 Bookmark |
| DELETE | `/api/bookmarks/:id` | `204` |
| GET | `/api/tags` | `200` 按书签数量降序排列的 `{ name, count }[]` |
| POST | `/api/translations` | `200` 翻译结果 |
| GET | `/api/docs` | `200` 当前 API 文档 |

## 错误结构

所有应用错误使用统一结构：

```json
{
  "error": {
    "code": "bookmark_url_conflict",
    "message": "A bookmark with this URL already exists",
    "details": { "url": "https://example.com" }
  }
}
```

当前响应模型、分页规则、请求示例和错误码表以运行时 `/api/docs` 为准。
