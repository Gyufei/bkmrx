# Todo V1 需求规格

## 1. 背景与目标

当前桌面应用已经提供书签与笔记功能。本期新增一个独立的轻量 Todo 页面，完成“快速记录、分类筛选、状态切换、编辑和删除”的本地任务闭环。

Todo 仅供当前桌面应用本机使用，数据写入现有 SQLite 数据库。不接入云同步、localhost HTTP API 或 Chrome 扩展。页面结构参考已确认的 UI 稿，视觉细节、组件、间距、主题和交互模式遵循现有项目。

## 2. 目标

1. 提供独立 Todo 导航与页面。
2. 支持快速创建和完整表单创建、编辑任务。
3. 支持进行中、已完成、挂起、已取消四种状态。
4. 使用独立 Todo 标签实现多对多分类，并支持标签重命名、合并和删除。
5. 支持单标签与单状态组合筛选，以及稳定的固定排序。
6. 延续当前 React、TanStack Query、Tauri command、Rust service/repository 和 SQLite 分层。

## 3. 非目标

- 不做截止日期、逾期、提醒或日历能力。
- 不做重复任务、子任务、批量操作或拖拽排序。
- 不做任务搜索。
- 不做软删除、撤销删除、回收站或恢复 UI。
- 不做 JSON 导入导出。
- 不做云同步，也不显示“已同步”。
- 不向 localhost HTTP API 或 Chrome 扩展暴露 Todo。
- 不做独立空标签创建入口或标签管理页面。
- 不做描述摘要、标签折叠或插画空状态。
- 不做复制标题、复制描述等额外右键菜单动作。

## 4. 信息架构

### 4.1 全局导航

顶部导航顺序为：

1. 书签
2. 笔记
3. Todo
4. 设置

Todo 使用 Lucide `ListTodo` 图标。当前应用继续使用内存页面状态切换，不引入路由库。

### 4.2 Todo 页面

页面分为左侧栏和主内容区。

左侧栏包含：

- “所有任务”入口；
- Todo 标签及任务数量；
- 标签右键菜单中的“重命名”和“删除”。

主内容区包含：

- 当前范围标题：未选择标签时为“所有任务”，选择标签时为标签名称；
- 快速添加输入框；
- “新建任务”按钮；
- “全部 / 进行中 / 已完成 / 挂起 / 已取消”五个状态页签；
- 任务列表；
- 左下角范围统计，如“12 个任务 · 3 个已完成”。

不保留参考稿中的“今天”和“已同步”。底部统计基于当前标签范围内的全部状态，不随顶部状态页签变化。

## 5. 数据模型

### 5.1 Todo

Todo 包含：

| 字段 | 语义 |
| --- | --- |
| `id` | 本地唯一标识 |
| `title` | 必填标题，保存前去除首尾空格；允许重复 |
| `description` | 可为空的纯文本描述 |
| `status` | `in_progress`、`completed`、`suspended`、`canceled` |
| `is_high_priority` | 是否高优先级 |
| `created_at` | 创建时间 |
| `updated_at` | 最近更新时间 |
| `completed_at` | 进入已完成状态的时间，否则为空 |

新任务固定为 `in_progress`。进入 `completed` 时填写 `completed_at`；离开 `completed` 时清空。挂起和取消不增加专用时间字段。

### 5.2 Todo 标签

Todo 标签与书签标签命名空间完全独立：

- 一个 Todo 可以关联多个标签；
- 一个标签可以关联多个 Todo；
- 使用独立 Todo 标签表和多对多关联表；
- 关联表使用复合唯一约束避免重复关系；
- 删除 Todo 时级联删除关系，但保留标签；
- 标签与最后一个 Todo 解除关系后仍然保留；
- 标签名称去除首尾空格且不能为空；
- 标签名称按 ASCII 大小写不敏感唯一，保留首次输入的展示形式；
- 暂不限制单个任务的标签数量和标签名称长度。

标签重命名为不存在的名称时直接更新。重命名为已存在标签时，在单一事务中将旧标签的所有任务关系合并到目标标签，去重后删除旧标签。

主动删除标签需要使用 shadcn `AlertDialog` 二次确认。确认后删除该标签及全部关系，不删除任何 Todo。

## 6. 创建与编辑

### 6.1 快速添加

- 输入标题后按 `Enter` 创建；
- 默认状态为进行中；
- 默认无标签、普通优先级、空描述；
- 提交期间阻止重复提交；
- 成功后清空输入框并刷新任务与标签数据；
- 失败时保留输入，并使用 shadcn 风格 toast 显示错误。

### 6.2 完整表单

“新建任务”与点击现有任务正文均打开与书签新建模式一致的 Dialog。表单字段为：

- 标题；
- 纯文本描述；
- Todo 标签；
- 高优先级开关。

表单不提供状态字段。必须点击“保存”才提交，关闭 Dialog 放弃未保存修改。标签可以选择已有项或在表单中直接创建；侧边栏不提供新建空标签按钮。

点击任务上的标签直接切换到该标签筛选，不打开编辑 Dialog。点击勾选控件或右键菜单也不打开编辑 Dialog。

## 7. 状态与右键菜单

### 7.1 列表状态控件

- 进行中：紫色或主题主色 `CircleDot`；点击变为已完成。
- 已完成：翠绿色 `CircleCheck`；点击变为进行中。
- 挂起：琥珀色 `CirclePause`；图标不可直接切换状态。
- 已取消：红色 `CircleX`；图标不可直接切换状态。

图标同时依赖形状和鲜明颜色表达状态，不新增图片资源或图标库。

### 7.2 右键菜单动作

| 当前状态 | 动作 |
| --- | --- |
| 进行中 | 编辑、挂起、取消任务、删除 |
| 挂起 | 编辑、取消挂起、取消任务、删除 |
| 已完成 | 编辑、重新打开、删除 |
| 已取消 | 编辑、重新打开、删除 |

取消挂起和重新打开都将状态设为进行中。状态动作立即保存，不弹确认框。

删除 Todo 立即执行物理删除，不弹确认、没有撤销。删除后级联清理 Todo 与标签的关系，但保留标签记录。

## 8. 筛选、计数与排序

### 8.1 筛选

- 侧边栏每次只能选择一个标签；
- 点击已选标签或“所有任务”回到无标签范围；
- 顶部每次选择一个状态页签；
- 标签与状态是两个正交筛选条件；
- 选择标签后先限定任务范围，再应用状态筛选；
- 标签旁数量统计该标签关联的全部状态任务，不随状态页签变化。

### 8.2 标签排序

- 标签按关联 Todo 总数倒序；
- 数量相同时按名称升序；
- 无任务标签显示为 `0` 并排在最后；
- 列表直接展示任务的全部标签，不提前实现折叠或 `+N`。

### 8.3 任务排序

“全部”页签按状态分组：

1. 进行中
2. 挂起
3. 已完成
4. 已取消

每个状态组内高优先级在普通任务之前，然后：

- 进行中按创建时间倒序；
- 挂起按更新时间倒序；
- 已完成按完成时间倒序；
- 已取消按更新时间倒序。

单状态页签使用对应状态内部排序。

## 9. 反馈与空状态

项目当前没有 toast 基础设施。本期增加基于 `@base-ui/react/toast` 的 shadcn Base UI `Toast` 和全局 `Toaster`。Todo 操作失败统一使用 toast 提示；快速创建失败还必须保留输入。常规成功操作不弹 toast，避免产生高频噪声。

空状态使用简洁文字，不使用插画：

- 没有任何任务：“还没有任务，创建一个开始吧”；
- 当前标签无任务：“该标签下暂无任务”；
- 当前状态无任务：显示对应状态的空结果文案。

加载和错误状态沿用现有页面模式，mutation pending 时禁用对应的重复操作。

## 10. 本地数据与集成边界

- Todo schema 随应用安装和数据库初始化自动提供；
- 现有数据库通过版本迁移增加 Todo 表；
- Todo mutation 成功后刷新 Todo 与 Todo 标签缓存；
- Rust service 在成功写入后发送统一 `todos-changed` 通知，使现有查询缓存模式保持一致；
- Todo 不进入现有书签 HTTP server，也不进入 Chrome extension；
- 不增加同步状态或跨设备契约。

## 11. 验收标准

1. 新数据库初始化和已有数据库升级都能获得完整 Todo schema，且不影响书签数据。
2. Todo CRUD、四状态切换、完成时间规则和物理删除符合规格。
3. Todo 标签支持创建、选择、单标签筛选、计数、排序、重命名、冲突合并和确认删除。
4. 快速添加、完整新建、编辑、状态图标和右键菜单均可正常操作。
5. 标签与状态组合筛选、固定排序和底部统计结果正确。
6. 空状态、pending 和错误 toast 可见且不会丢失快速输入。
7. Todo 页面与现有主题、导航和 Dialog 模式一致。
8. 前端测试、Rust 测试和生产构建全部通过，没有修改 HTTP API 或扩展契约。
