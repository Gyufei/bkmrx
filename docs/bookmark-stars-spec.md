# 书签星标功能规格

## 目标

让常用书签在不输入搜索词时直接可见，同时保持现有文本搜索和标签筛选行为不变。

## 用户体验

- 搜索词为空且未选择标签时，只展示星标书签。
- 星标书签按最近加星时间倒序排列；同一时间以书签 ID 倒序稳定排序。
- 输入搜索词后继续使用现有搜索逻辑，星标不影响相关性排序。
- 搜索词为空但选择了标签时继续使用现有标签查询逻辑。
- 没有星标书签时显示：`暂无星标书签。在搜索结果中点击星形按钮，即可将常用书签显示在这里。`
- 书签卡片右上角提供独立星形按钮；空心代表未星标，实心代表已星标。
- 点击星形按钮不得触发打开书签的行为，并提供对应的 title 与无障碍名称。
- 添加星标无需确认。
- 在默认星标列表中取消星标前弹出确认；确认后卡片立即消失。
- 在搜索或标签结果中取消星标无需确认，卡片继续保留在当前结果中。
- 取消后重新星标会更新加星时间，并使书签回到星标列表首位。

## 数据模型

- `bookmarks` 表增加可空整数列 `starred_at`，保存 UTC Unix 毫秒时间戳。
- `starred_at IS NOT NULL` 表示已星标，`NULL` 表示未星标。
- 不增加冗余布尔字段，也不提前引入多类型标记枚举。
- 数据库 schema 从 v1 升级至 v2；v1 数据迁移后所有书签默认为未星标。

## 导入导出

- 继续使用导出格式版本 1，在单条书签记录中增加可选字段 `starred_at`。
- 新版导出始终输出 `starred_at`，值为 RFC 3339 时间或 `null`。
- 新建导入记录：字段缺失或为 `null` 时未星标，非空时使用导入值。
- 合并本地记录：字段缺失时保留本地值；字段明确存在时，仅在导入记录的 `updated_at` 更新时覆盖本地值。
- `starred_at` 必须是合法 RFC 3339 时间；非法值导致预览和导入失败。

## 非目标

- 不新增首页或导航页。
- 不实现多类型标记、稍后阅读或重要状态。
- 不实现手动排序、批量星标或自动跨设备同步。
- 不修改文本搜索相关性算法和标签筛选语义。

## 验收标准

1. v1 数据库可无损迁移至 v2，新建数据库直接使用 v2 schema。
2. 星标与取消星标能持久化并发出书签变更通知；不存在的书签返回稳定的 not-found 错误。
3. 空搜索且无标签只分页返回星标记录，顺序和游标稳定；其他查询路径保持现状。
4. 导出、导入、旧备份兼容和冲突覆盖规则均有自动化测试。
5. 前端空状态、星标切换、取消确认和查询模式切换均有自动化测试。
6. Rust 测试、前端测试、TypeScript 构建全部通过。
