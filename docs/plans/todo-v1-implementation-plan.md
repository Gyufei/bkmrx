# Todo V1 实施计划

本计划以 [Todo V1 需求规格](../specs/todo-v1-spec.md) 为唯一产品范围。实施遵循测试驱动和最小改动原则：每个阶段先添加能够验证目标行为的测试，再实现最小代码使其通过，最后运行相关回归测试。

## 1. 数据库 schema 与迁移

### 工作

- 为当前 SQLite schema 增加下一版本迁移。
- 新数据库创建 `todos`、`todo_tags` 和 Todo/标签关联表。
- 为状态、优先级、时间字段、标签大小写不敏感唯一性和关系唯一性增加必要约束。
- 为状态筛选、标签关联查询和固定排序增加最小必要索引。
- 已有数据库从当前版本升级时只新增 Todo schema，不改变书签数据。

### 先写测试

- 新数据库包含完整 Todo schema、外键和索引。
- 当前 schema 升级到新版本后保留已有书签和标签数据。
- 重复 Todo 标签关系被约束拒绝。
- Todo 删除级联清理关系但不删除 Todo 标签。
- Todo 标签名称按大小写不敏感规则保持唯一。

### 验证

运行数据库 repository/migration 集成测试，确认初始化和升级路径均通过。

## 2. Rust 领域模型与 Repository

### 工作

- 新增 `todos` 模块及 Todo、TodoStatus、TodoTag、请求和筛选模型。
- 实现创建、读取、更新、物理删除和四状态转换。
- 使用事务完整替换任务标签关系，并保留无任务标签。
- 实现标签列表、创建、重命名、冲突合并和删除。
- 实现单标签与单状态组合查询、标签计数、底部统计和固定排序。
- 所有 SQL 保持参数化，Repository 负责时间戳和数据库一致性。

### 先写测试

- 标题 trim、空标题拒绝、重复标题允许。
- 新任务默认字段和创建时间正确。
- 更新内容不会隐式改变状态。
- 完成时写入 `completed_at`，离开完成时清空。
- 进行中、完成、挂起、取消和恢复转换正确。
- 删除 Todo 为物理删除，标签记录继续存在。
- 标签 trim、去空、忽略大小写去重、多标签关系正确。
- 标签重命名到已有名称时关系无重复合并。
- 删除标签只删除标签和关系，不删除 Todo。
- 单标签/状态组合筛选、全部状态分组排序和各状态内部排序正确。
- 标签计数包含全部状态，零任务标签保留并排在末尾。

### 验证

运行 Todo repository 集成测试与现有数据库回归测试。

## 3. Service、Tauri Commands 与事件

### 工作

- 新增 Todo service，封装 Repository 用例。
- 只有成功 mutation 才发送 `todos-changed`。
- 在 Tauri state 中注册 service，并注册 Todo CRUD、状态、标签与查询 commands。
- 不修改 Axum HTTP server 或 Chrome extension。

### 先写测试

- 每个成功 mutation 发送一次变更通知。
- validation、not-found 或数据库错误不发送成功通知。
- command 输入输出与领域请求保持一致。

### 验证

运行 Todo service 测试及 Rust 全量测试。

## 4. TypeScript 契约与查询层

### 工作

- 增加 Todo、状态、标签、筛选、统计和 mutation 的 TypeScript 类型。
- 在现有 invoke 边界增加 Todo commands 的薄封装。
- 新增 Todo API adapter、TanStack Query keys 和 mutations。
- `todos-changed` 到达时失效 Todo 与 Todo 标签查询。
- 查询键显式包含标签和状态，避免不同视图共享错误缓存。

### 先写测试

- invoke 命令名、参数映射和返回值正确。
- query key 包含标准化标签与状态。
- mutation 成功后刷新 Todo、标签和统计查询。
- Todo 事件只失效 Todo 相关缓存。

### 验证

运行 Todo API/query 单测与现有前端回归测试。

## 5. Toast 基础设施

### 工作

- 增加基于现有 `@base-ui/react/toast` 的 shadcn Base UI `Toast` 组件，不引入额外依赖。
- 在应用根节点挂载一次 `Toaster`。
- Todo 操作错误使用 toast；常规成功操作保持静默。

### 先写测试

- 应用根节点包含全局 Toaster。
- Todo mutation 失败调用错误 toast。
- 快速创建失败时输入值不被清空。

### 验证

运行 App 和 Todo 页面相关测试。

## 6. 导航与 Todo 页面骨架

### 工作

- 在现有内存导航中新增 Todo path、`ListTodo` tab 和明确的 Layout 分支。
- 新增 Todo 页面与局部组件目录。
- 实现侧边栏、页面标题、状态页签、底部统计、加载/错误/空状态布局。
- 视觉完全复用现有 CSS token、Button、Input、Tabs、Dialog、AlertDialog 和 ContextMenu。

### 先写测试

- 点击 Todo tab 显示 Todo 页面，书签、笔记和设置切换不回归。
- “所有任务”和标签范围标题正确。
- 五个状态页签发送正确筛选。
- 标签数量和底部统计不随状态页签错误变化。
- 三类空状态文案正确。

### 验证

运行 Navbar、Layout、App 和 Todo 页面测试。

## 7. 创建与编辑交互

### 工作

- 实现顶部单行快速添加，`Enter` 提交。
- 实现新建/编辑共用的完整 Dialog。
- 复用或按现有模式适配标签输入，数据源限定为 Todo 标签。
- 表单只包含标题、纯文本描述、标签和高优先级开关。
- 成功关闭并刷新；pending 禁止重复提交；失败保留当前输入并 toast。

### 先写测试

- 快速添加使用正确默认值，成功后清空。
- 空标题不提交，重复标题允许提交。
- 快速添加 pending 时不会重复创建，失败时保留输入并 toast。
- 新建 Dialog 默认值正确，保存前不会持久化。
- 编辑 Dialog 回填字段，保存内容时不改变状态。
- 标签可选择已有项或创建新项。

### 验证

运行快速添加、Dialog、标签输入和页面 mutation 测试。

## 8. 列表、状态和右键菜单

### 工作

- 实现任务行、全部标签展示、高优先级标识和四种鲜明状态图标。
- 进行中与已完成图标支持二态点击切换。
- 挂起和已取消图标不可直接切换。
- 使用通用 ContextMenu 按当前状态渲染动作矩阵。
- 任务正文打开编辑；标签点击切换筛选；内部控件阻止冒泡。
- 删除立即物理删除，不显示确认。

### 先写测试

- 四状态图标、颜色语义和可访问名称正确。
- 进行中/完成点击转换正确，挂起/取消图标不触发转换。
- 每个状态只显示规格中的右键动作。
- 挂起、取消挂起、取消、重新打开即时 mutation 正确。
- 点击正文、标签、状态控件和菜单互不误触。
- 删除不弹确认并立即调用 mutation。

### 验证

运行 Todo 列表与 ContextMenu 交互测试。

## 9. 标签生命周期 UI

### 工作

- 侧边栏按数量倒序、名称升序展示所有 Todo 标签和数量。
- 标签右键重命名使用小型 Dialog。
- 重命名冲突由后端事务自动合并，前端刷新筛选和标签数据。
- 标签删除使用 shadcn AlertDialog，明确只删除标签关系、不删除任务。
- 若当前筛选标签被合并或删除，安全回到目标标签或“所有任务”。

### 先写测试

- 零任务标签继续显示并可操作。
- 标签重命名和冲突合并后筛选状态正确。
- 删除必须确认，取消不执行，确认后不删除 Todo。
- 当前筛选标签删除后回到“所有任务”。
- 点击任务行标签切换为单标签筛选。

### 验证

运行 TodoSidebar 和 Todo 页面集成测试。

## 10. 集成验证与视觉检查

### 自动化验证

- 运行前端 Todo 相关测试。
- 运行前端全量测试。
- 运行前端生产构建和 TypeScript 检查。
- 运行 Rust Todo 相关测试。
- 运行 Rust 全量测试和格式检查。

### 手工验证

- 在浅色和深色主题检查页面布局与四状态颜色。
- 验证导航、快速添加、完整新建、编辑、标签筛选和五状态页签。
- 验证所有右键菜单状态转换、标签合并/删除和物理删除。
- 验证空数据、零任务标签、pending 和数据库失败反馈。
- 验证应用重启后 Todo 与标签数据仍存在。

### 最终质量门槛

- 对最终 diff 做多轴代码审查。
- 每处改动都能追溯到规格或验证需要。
- 不包含同步、HTTP API、扩展、导入导出、日期或回收站等范围外能力。
- 所有自动化检查通过，视觉与交互验收无阻断问题。
